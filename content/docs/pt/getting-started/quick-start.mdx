Este guia irá orientá-lo na criação de sua primeira carteira Account Abstraction usando a API MSA. Você aprenderá o fluxo de trabalho essencial e verá exemplos práticos em múltiplas linguagens de programação.

## Pré-requisitos

Antes de começar, certifique-se de ter:

1. **Chave da API**: Sua chave da API MSA (obtenha em [Entre em Contato](https://calendly.com/omnes-blockchain/30min))
2. **Credenciais de Assinatura**: Uma das seguintes:
   - **Chave Privada** (para teste): Sua chave privada Ethereum
   - **HSM Fireblocks**: ID do Cliente e ID da Versão
   - **MPC Fireblocks**: ID do Cliente e ID do Ativo
   - **Google Cloud KMS**: Credenciais GCP e informações da chave
3. **Acesso à Rede**: Endpoint RPC para sua rede alvo
4. **API Base URL**: `https://api.msa.omnes.tech`

### Passo 0: Obtenha Sua Chave da API

Se você ainda não tem uma chave da API:

1. [Agende uma reunião](https://calendly.com/omnes-blockchain/30min?month=2025-11) com nossa equipe, ou
2. [Envie-nos um email](mailto:gus@omnes.dev) para solicitar acesso

Assim que receber sua chave da API, armazene-a com segurança:

```bash
# arquivo .env
API_KEY=sua-chave-api-aqui
PRIVATE_KEY=0x1234... # Apenas para testes
RPC_URL=https://rpc-amoy.polygon.technology/
```

## Passo 1: Inicializar o SDK

Primeiro, configure seu ambiente e inicialize o SDK com sua chave da API e signatário.

<Tabs items={["TypeScript SDK", "REST API"]}>
<Tab value="TypeScript SDK">

### Usando SmartWallet SDK (Recomendado)

```typescript
import { SmartWallet, PKSigner } from '@omnes/smartwallet-ts-sdk';

// Carregar variáveis de ambiente
const apiKey = process.env.API_KEY!;
const rpcURL = process.env.RPC_URL!;
const privateKey = process.env.PRIVATE_KEY!; // Apenas para testes

// Criar um signatário
const signer = await PKSigner.create(privateKey as `0x${string}`);

// Inicializar SmartWallet com chave da API
const smartWallet = await SmartWallet.create(
  signer.signMessage,           // Método de assinatura de mensagem
  signer.signMessage,           // Método de assinatura de hash UserOp
  signer.getEVMAddress(),       // Endereço do signatário
  rpcURL,                       // Endpoint RPC
  apiKey,                       // Sua chave da API (obrigatória!)
  null,                         // Contratos (null = buscar da API)
  false                         // Usar bundler remoto
);

console.log('SmartWallet initialized successfully!');
```

## Passo 3: Financiar a Carteira (Opcional)

Para que a criação da carteira tenha sucesso, o endereço previsto precisa de tokens nativos suficientes para pagar o gas. Você pode:

1. **Enviar tokens** para o endereço previsto de outra carteira
2. **Usar um paymaster** para patrocinar a transação
3. **Financiar via faucet** (apenas testnet)

```bash
# Exemplo: Enviar 0.1 MATIC para o endereço previsto

  --value 0.1ether \
  --rpc-url https://rpc-amoy.polygon.technology/
```

## Passo 4: Criar a Carteira

Implante a carteira. Isso requer credenciais de assinatura (chave privada para testes, ou HSM/MPC para produção).

<Tabs items={["TypeScript SDK", "REST API"]}>
<Tab value="TypeScript SDK">

```typescript
import { SmartWallet, PKSigner, AccountOperations, Operation } from '@omnes/smartwallet-ts-sdk';

// Inicializar SmartWallet (do Passo 1)
const signer = await PKSigner.create(privateKey as `0x${string}`);
const smartWallet = await SmartWallet.create(
  signer.signMessage,
  signer.signMessage,
  signer.getEVMAddress(),
  rpcURL,
  apiKey,
  null,
  false // Usar bundler remoto (requer chave da API)
);

// Criar operação de carteira
const accountOperations: AccountOperations[] = [{
  account: {
    walletCustody: 1, // ECDSA_VALIDATOR (1)
    salt: "user@example.com",
    publicKeys: []
  },
  operations: [], // Array de operações vazio = apenas criar carteira
  settings: {}
}];

// Criar carteira usando bundler remoto
const result = await smartWallet.buildAndRequestSendUserOperations(
  accountOperations,
  [], // useABI
  []  // signatários adicionais
);

console.log('Carteira criada!');
console.log('Hash da transação:', result.txHash);
console.log('Status:', result.status === 1 ? 'Sucesso' : 'Falhou');
```

## Exemplo Completo do Fluxo de Trabalho

Aqui está um exemplo completo de ponta a ponta usando o SmartWallet SDK:

```typescript
import { SmartWallet, PKSigner, AccountOperations, Operation } from '@omnes/smartwallet-ts-sdk';
import dotenv from 'dotenv';

dotenv.config();

async function completeWalletWorkflow() {
  // Carregar configuração
  const apiKey = process.env.API_KEY!;
  const rpcURL = process.env.RPC_URL!;
  const privateKey = process.env.PRIVATE_KEY!;
  const userSalt = `user-${Date.now()}@example.com`;

  try {
    // Passo 1: Inicializar SmartWallet
    console.log('🔧 Inicializando SmartWallet...');
    const signer = await PKSigner.create(privateKey as `0x${string}`);
    const smartWallet = await SmartWallet.create(
      signer.signMessage,
      signer.signMessage,
      signer.getEVMAddress(),
      rpcURL,
      apiKey,
      null, // Contratos serão buscados da API usando a chave da API
      false // Usar bundler remoto
    );
    console.log('✅ SmartWallet inicializado');

    // Passo 2: Prever endereço da carteira
    console.log('🔮 Prevendo endereço da carteira...');
    const predictedAddress = smartWallet.predictWalletAddress(userSalt);
    console.log(`✅ Endereço previsto: ${predictedAddress}`);

    // Passo 3: Verificar se a carteira existe
    console.log('🔍 Verificando existência da carteira...');
    const accountOperations: AccountOperations[] = [{
      account: {
        walletCustody: 1,
        salt: userSalt,
        publicKeys: []
      },
      operations: [],
      settings: {}
    }];
    
    // Verificar existência da carteira usando checkAccounts
    const accounts = await smartWallet.checkAccounts([userSalt], []);
    const walletExists = accounts[0]?.exists || false;
    
    if (walletExists) {
      console.log('ℹ️ Carteira já existe');
    } else {
      console.log('ℹ️ Carteira não existe, será criada');
    }

    // Passo 4: Criar carteira (se necessário)
    if (!walletExists) {
      console.log('🏗️ Criando carteira...');
      const createResult = await smartWallet.buildAndRequestSendUserOperations(
        accountOperations,
        [],
        []
      );
      console.log(`✅ Carteira criada! Tx: ${createResult.txHash}`);
      // Aguardar confirmação
      await new Promise(resolve => setTimeout(resolve, 5000));
    }

    // Passo 5: Executar uma transação
    console.log('⚡ Executando transação...');
    const operation: Operation = {
      to: "0x097d4Aed5924e2172451973153Fc0e03407eD1F9", // Endereço do token
      value: BigInt(0),
      funcSignature: "approve(address,uint256)",
      params: [
        "0xA65aae78EdEF916d4102BA7b5672068C0D35fbff", // Spender
        BigInt("1000000000000000000") // Quantidade
      ]
    };

    const executeOperations: AccountOperations[] = [{
      account: accountOperations[0].account,
      operations: [operation],
      settings: {}
    }];

    const executeResult = await smartWallet.buildAndRequestSendUserOperations(
      executeOperations,
      [],
      []
    );
    console.log(`✅ Transação executada! Tx: ${executeResult.txHash}`);

    return {
      walletAddress: predictedAddress,
      txHash: executeResult.txHash
    };

  } catch (error) {
    console.error('❌ Erro:', error);
    throw error;
  }
}

// Executar o fluxo de trabalho
completeWalletWorkflow()
  .then(result => {
    console.log('🎉 Fluxo de trabalho concluído com sucesso!');
    console.log('Resultado:', result);
  })
  .catch(error => {
    console.error('💥 Fluxo de trabalho falhou:', error);
    process.exit(1);
  });
```

## Problemas Comuns e Soluções

### 1. Gas Insuficiente

**Erro**: Transação falha com "fundos insuficientes"

**Solução**: Certifique-se de que o endereço previsto da carteira tenha tokens nativos suficientes:

```typescript
// Verificar saldo antes de criar
const balance = await provider.getBalance(walletAddress);
console.log('Saldo da carteira:', ethers.utils.formatEther(balance));
```

### 2. Chave da API Inválida

**Erro**: "Chave da API inválida" ou "Não autorizado"

**Solução**: 
- Verifique se sua chave da API está correta: `echo $API_KEY`
- Certifique-se de que a chave da API está incluída no cabeçalho `X-API-Key` para requisições REST API
- Verifique se sua chave da API é passada para `SmartWallet.create()` ao usar o SDK
- Solicite uma nova chave da API se necessário: [Entre em Contato](https://calendly.com/omnes-blockchain/30min)

### 3. ID do Cliente Inválido ou Credenciais de Assinatura Inválidas

**Erro**: "ID do cliente inválido" ou falha de autenticação

**Solução**: Verifique suas credenciais do Fireblocks:

```bash
# Verificar variáveis de ambiente
echo $FIREBLOCKS_CLIENT_ID
echo $FIREBLOCKS_VERSION_ID
```

### 4. Problemas de Conexão de Rede

**Erro**: "Falha na conexão de rede"

**Solução**: Verifique o endpoint RPC e o status da rede:

```bash
# Testar endpoint RPC
curl -X POST https://rpc-amoy.polygon.technology/ \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```
