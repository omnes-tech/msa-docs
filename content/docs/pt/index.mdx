Bem-vindo à documentação da **API MSA (Multi-Signature Account)**. Esta API abrangente permite criar e gerenciar carteiras Account Abstraction (AA) com recursos avançados de segurança, incluindo validação multi-assinatura, autenticação passkey e assinatura HSM/MPC.

## O que é a API MSA?

A API MSA é um serviço robusto baseado em Go que fornece:

- **Carteiras Account Abstraction**: Crie carteiras de smart contract com lógica programável
- **Múltiplos Tipos de Custody**: Suporte para validação ECDSA, Passkey e Multi-assinatura
- **Segurança Empresarial**: Integração com serviços de assinatura HSM/MPC (Fireblocks)
- **Suporte Multi-Chain**: Funciona em múltiplas redes compatíveis com EVM
- **Amigável para Desenvolvedores**: API RESTful com SDKs abrangentes

## Tipos de Custody Suportados

A API MSA suporta cinco configurações diferentes de custody de carteira:

| Tipo | Descrição | Casos de Uso |
|------|-----------|--------------|
| **ECDSA_VALIDATOR** (1) | Validação de assinatura ECDSA tradicional | Operações padrão de carteira |
| **ECDSA_PASSKEY_VALIDATOR** (2) | Validação híbrida ECDSA + Passkey | Segurança aprimorada com biometria |
| **PASSKEY_VALIDATOR** (3) | Validação baseada apenas em passkey | Autenticação sem senha |
| **MULTISIG_VALIDATOR** (4) | Configuração tradicional de multi-assinatura | Cenários de custody compartilhada |
| **MULTISIG_PASSKEY_VALIDATOR** (5) | Multi-sig com suporte a passkey | Segurança de nível empresarial |

## Visão Geral da API

A API MSA fornece as seguintes categorias principais de endpoints:

- **Gerenciamento de Carteiras**: Criar, prever e verificar status da carteira
- **Execução de Transações**: Executar operações com vários métodos de validação
- **Gerenciamento de Gas**: Estimar e otimizar custos de transação
- **Interação com Contratos**: Ler estado do contrato e decodificar eventos
- **Utilitários**: Assinatura de mensagens, busca de recibos e solução de problemas

## Stack Tecnológico

A API MSA é construída com tecnologias modernas:

- **Backend**: Serviço de API baseado em Go
- **Assinatura**: Integração Fireblocks HSM/MPC
- **Smart Contracts**: Account Abstraction ERC-4337
- **SDK**: SDK TypeScript (`@omnes/smartwallet-ts-sdk`)
- **Exemplos**: Exemplos HTTP para JavaScript, Python, cURL
- **Redes**: Polygon, Base, Ethereum (todas as chains compatíveis com EVM)
