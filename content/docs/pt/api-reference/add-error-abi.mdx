Adicionar ABIs de erros personalizados ao sistema.

## Endpoint

```
POST /addError
```

## Descrição

Adiciona ABIs de erros personalizados ao sistema para uso em decodificação de erros.

## Corpo da Solicitação

```json
{
  "errorABI": {
    "type": "error",
    "name": "ECDSAInvalidSignatureS",
    "inputs": [
      {
        "name": "s",
        "type": "bytes32",
        "internalType": "bytes32"
      }
    ]
  }
}
```

## Resposta

```json
{
  "status": 200,
  "errorDef": "error ECDSAInvalidSignatureS(bytes32 indexed s)"
}
```

### Campos da Resposta

- **`status`** (integer): Código de status HTTP (200 para sucesso)
- **`errorDef`** (string): A string de definição de erro canônica

```python
import requests

url = "https://api.msa.omnes.tech/addError"
payload = {
    "errorABI": {
        "type": "error",
        "name": "ECDSAInvalidSignatureS",
        "inputs": [
            {
                "name": "s",
                "type": "bytes32",
                "internalType": "bytes32"
            }

result = response.json()
print(f"Erro registrado: {result['errorDef']}")
```

## Casos de Uso

- **Erros personalizados**: Registrar erros de smart contracts personalizados
- **Decodificação de erros**: Habilitar decodificação adequada de erros de contratos personalizados
- **Depuração**: Melhores mensagens de erro para depuração de transações falhadas
- **Integração**: Suportar integração com qualquer contrato compatível com EVM

## Melhores Práticas

1. **Registrar antes de usar**: Adicione ABIs de erros antes de transações que possam usá-los
2. **Usar formato correto**: Garanta que o formato ABI corresponda à definição de erro Solidity
3. **Tratar duplicatas**: Verifique se o erro já existe antes de adicionar
4. **Validar ABI**: Garanta que o ABI do erro seja válido antes do registro
