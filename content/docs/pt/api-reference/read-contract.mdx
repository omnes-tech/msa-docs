Ler estado de smart contract da blockchain.

## Endpoint

```
POST /read
```

## Descrição

Lê o estado de smart contracts da blockchain chamando funções view.

## Corpo da Solicitação

```json
{
  "reads": [
    {
      "to": "0xB72F28d9c0f72d488813E57581C17C466855E1F7",
      "funcSignature": "balanceOf(address)",
      "funcParams": ["0x28097eF2268B553783D9c32A33ECb1bB78B209F3"],
      "returnSignature": "uint256",
      "from": "0x28097eF2268B553783D9c32A33ECb1bB78B209F3"
    }
  ],
  "rpc": "https://polygon-amoy.infura.io/v3/{key}"
}
```

## Resposta

```json
[
  {
    "readIndex": 0,
    "results": ["1000000000000000000"],
    "errors": null
  }
]
```

### Campos da Resposta

- **`readIndex`** (integer): O índice da operação de leitura no array de solicitação
- **`results`** (array): Os valores de retorno decodificados da função do contrato
- **`errors`** (string, nullable): Mensagem de erro se a operação de leitura falhou

## Casos de Uso

- **Saldos de tokens**: Verificar saldos de tokens ERC-20
- **Estado do contrato**: Ler qualquer estado público do contrato
- **Leituras em lote**: Ler múltiplos valores de contrato em uma única solicitação
- **Validação de dados**: Verificar estado do contrato antes de operações

## Melhores Práticas

1. **Usar assinaturas de retorno corretas**: Garanta que a assinatura de retorno corresponda ao tipo de retorno da função
2. **Tratar erros**: Verifique erros no array de resposta
3. **Operações em lote**: Leia múltiplos valores em uma única solicitação para eficiência
4. **Validar endereços**: Garanta que os endereços dos contratos estão corretos
