Assinar mensagens arbitrárias com chaves HSM/MPC.

## Endpoint

```
POST /sign
```

## Descrição

Assina mensagens arbitrárias usando chaves HSM/MPC. Suporta tanto mensagens brutas quanto dados estruturados EIP-712.

## Corpo da Solicitação

```json
{
  "messages": [
    "hello world",
    "hello web3"
  ],
  "format": "rsv",
  "hashed": false,
  "signer": {
    "clientId": "your-fireblocks-client-id",
    "versionId": "1"
  },
  "eip712": {
    "address": "0x...",
    "chainId": "137"
  }
}
```

## Resposta

```json
[
  {
    "address": "0xdb074b3c323a7ad418ebbe66bad231f43f680563",
    "publicKey": "049113caedb5d570dc9a47974f819b9d2c88ffcf622c1f3c756be7955d9f16eae28d8f00ec4fa359c311ae4c25b58d2b1d872d6e4c37600494416d856615fb7e4b",
    "signatures": [
      {
        "r": "...",
        "s": "...",
        "v": 27
      }
    ],
    "errors": null
  }
]
```

### Campos da Resposta

- **`address`** (string): O endereço público do signatário
- **`publicKey`** (string): A chave pública do signatário
- **`signatures`** (array): Array de objetos de assinatura com valores r, s, v
- **`errors`** (array, nullable): Array de mensagens de erro se a assinatura falhou

import requests

url = "https://api.msa.omnes.tech/sign"
payload = {
    "messages": [
        "hello world",
        "hello web3"
    ],
    "format": "rsv",
    "hashed": False,

## Casos de Uso

- **Autenticação de mensagens**: Assinar mensagens para fins de autenticação
- **Assinatura EIP-712**: Assinar dados estruturados para dApps
- **Assinatura em lote**: Assinar múltiplas mensagens em uma única solicitação
- **Assinatura HSM/MPC**: Usar infraestrutura de assinatura de nível empresarial

## Melhores Práticas

1. **Usar EIP-712 para dados estruturados**: Use formato EIP-712 para melhor UX e segurança
2. **Tratar erros**: Verifique erros no array de resposta
3. **Verificar assinaturas**: Sempre verifique assinaturas on-chain ou off-chain
4. **Proteger credenciais**: Nunca exponha credenciais HSM/MPC
