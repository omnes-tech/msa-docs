# Documentação Interativa da API

Explore e teste os endpoints da API MSA diretamente no seu navegador. Esta documentação interativa é powered by Scalar e fornece uma visão abrangente de todos os endpoints disponíveis, schemas de request/response e exemplos.

## Recursos

- **Experimente**: Execute chamadas reais da API diretamente da documentação
- **Configuração de Autenticação**: Configure suas credenciais HSM/MPC para testes
- **Exemplos Request/Response**: Veja exemplos em tempo real em múltiplos formatos
- **Validação de Schema**: Validação automática de payloads de request
- **Exemplos Multi-Linguagem**: Amostras de código em cURL, JavaScript, Python e mais

## Como Começar

1. **Configure suas credenciais** na seção de autenticação
2. **Escolha um endpoint** da navegação lateral
3. **Preencha os parâmetros necessários** usando os formulários interativos
4. **Execute a solicitação** e veja respostas em tempo real

## Navegação Rápida

### Gerenciamento de Carteiras
- **POST /predict** - Prever endereços de carteira antes da criação
- **POST /create** - Implantar novas carteiras Account Abstraction
- **POST /check** - Verificar existência e status da carteira

### Execução de Transações
- **POST /execute** - Executar operações com parâmetros legíveis
- **POST /executeEncoded** - Executar UserOperations pré-codificadas
- **POST /executePasskey** - Executar com validação passkey
- **POST /estimateGas** - Estimar custos de gas para operações

### Interação com Contratos
- **POST /read** - Ler estado de smart contract
- **POST /receipt** - Obter recibos de transação
- **POST /filterEvent** - Filtrar eventos da blockchain
- **POST /getEvents** - Recuperar eventos específicos

### Utilitários
- **POST /sign** - Assinar mensagens arbitrárias
- **POST /getSigner** - Obter informações do signatário
- **POST /unstuck** - Resolver transações travadas
- **POST /passkeyHash** - Gerar hashes passkey

### Gerenciamento
- **POST /transactSigner** - Transações diretas HSM/MPC
- **POST /addEvent** - Adicionar ABIs de eventos personalizados
- **POST /addError** - Adicionar ABIs de erros personalizados

## Limites de Taxa

A API MSA implementa limitação de taxa para garantir uso justo:

| Nível | Solicitações por Minuto | Solicitações por Hora |
|-------|--------------------------|-----------------------|
| Gratuito | 60 | 1.000 |
| Pro | 300 | 10.000 |
| Empresarial | 1.000 | 50.000 |

## Códigos de Erro

Códigos de status HTTP comuns e seus significados:

| Código | Status | Descrição |
|--------|--------|-----------|
| 200 | OK | Solicitação bem-sucedida |
| 400 | Bad Request | Parâmetros de solicitação inválidos |
| 401 | Unauthorized | Credenciais de autenticação inválidas |
| 422 | Unprocessable Entity | Solicitação válida mas execução falhou |
| 429 | Too Many Requests | Limite de taxa excedido |
| 500 | Internal Server Error | Erro do lado do servidor |
