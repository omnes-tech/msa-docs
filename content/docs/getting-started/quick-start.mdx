# Quick Start Guide

This guide will walk you through creating your first Account Abstraction wallet using the MSA API. You'll learn the essential workflow and see practical examples in multiple programming languages.

## Prerequisites

Before starting, ensure you have:

- **Fireblocks Credentials**: Client ID and Version ID (HSM) or Asset ID (MPC)
- **Network Access**: RPC endpoint for your target blockchain
- **API Base URL**: `https://api.msa.omnes.tech`

## Step 1: Predict Wallet Address

First, let's predict the wallet address without deploying it. This is useful for funding the wallet before creation.

<Tabs items={["TypeScript", "Python", "cURL"]}>
<Tab value="TypeScript">

```typescript
import { MSAClient } from '@omnes/msa-sdk';

const client = new MSAClient({
  baseURL: 'https://api.msa.omnes.tech',
  defaultSettings: {
    rpc: 'https://rpc-amoy.polygon.technology/',
    factory: '0xb09Fd1134553a43A3E02182a6B04F4dEBa7476F4',
    validator: '0x9bD18Da66990F80d598dE02d5143dC9A4422eC3a',
    entryPoint: '0x5FF137D4b0FDCD49DcA30c7CF57E578a026d2789',
    beaconAdminAddress: '0x99Ee7725D6a8f691d8B375e0aD33d1Aff2236618'
  }
});

async function predictWallet() {
  const result = await client.predict({
    accounts: [{
      walletCustody: 1, // ECDSA_VALIDATOR
      salt: "user@example.com"
    }],
    settings: client.defaultSettings
  });
  
  console.log('Predicted wallet address:', result.predictions[0].wallet);
  return result.predictions[0].wallet;
}

const walletAddress = await predictWallet();
```

```python
import requests

def predict_wallet():
```

## Step 2: Fund the Wallet (Optional)

For wallet creation to succeed, the predicted address needs sufficient native tokens to pay for gas. You can:

1. **Send tokens** to the predicted address from another wallet
2. **Use a paymaster** to sponsor the transaction
3. **Fund via faucet** (testnet only)

```bash
# Example: Send 0.1 MATIC to the predicted address
# (Replace with actual wallet address from Step 1)
cast send 0x28097eF2268B553783D9c32A33ECb1bB78B209F3 \
  --value 0.1ether \
  --rpc-url https://rpc-amoy.polygon.technology/
```

## Step 3: Create the Wallet

Now let's deploy the wallet. This requires HSM/MPC signing credentials.

<Tabs items={["TypeScript", "Python", "cURL"]}>
<Tab value="TypeScript">

```typescript
async function createWallet() {
  const result = await client.create({
    accounts: [{
      walletCustody: 1, // ECDSA_VALIDATOR
      salt: "user@example.com"
    }],
    settings: {
      ...client.defaultSettings,
      beaconAdminCreationCode: "0x60a060405260405161059d38038061059d...", // Full bytecode
      signer: {
        clientId: "e94aecb1-5daf-47f3-948f-2a639a56baa6",
        versionId: "1"
      }
    }
  });
  
  console.log('Wallet created!');
  console.log('Transaction hash:', result.txHash);
  console.log('Status:', result.status === 1 ? 'Success' : 'Failed');
  
  return result;
}

const createResult = await createWallet();
```

## Step 5: Execute Your First Transaction

Now let's execute a simple transaction from the wallet. We'll approve an ERC-20 token:

<Tabs items={["TypeScript", "Python", "cURL"]}>
<Tab value="TypeScript">

```typescript
async function executeTransaction() {
  const result = await client.execute({
    operations: [{
      walletCustody: 1,
      salt: "user@example.com",
      to: "0x097d4Aed5924e2172451973153Fc0e03407eD1F9", // Token address
      funcSignature: "approve(address,uint256)",
      funcParams: [
        "0xA65aae78EdEF916d4102BA7b5672068C0D35fbff", // Spender
        "1000000000000000000" // Amount (1 token)
      ]
    }],
    settings: {
      ...client.defaultSettings,
      signer: {
        clientId: "e94aecb1-5daf-47f3-948f-2a639a56baa6",
        versionId: "1"
      }
    }
  });
  
  console.log('Transaction executed!');
  console.log('Transaction hash:', result.txHash);
  
  return result;
}

const executeResult = await executeTransaction();
```

## Complete Workflow Example

Here's a complete end-to-end example combining all steps:

```typescript
import { MSAClient, CustodyType } from '@omnes/msa-sdk';

async function walletWorkflow() {
  const client = new MSAClient({
    baseURL: 'https://api.msa.omnes.tech',
    defaultSettings: {
      rpc: 'https://rpc-amoy.polygon.technology/',
      factory: '0xb09Fd1134553a43A3E02182a6B04F4dEBa7476F4',
      validator: '0x9bD18Da66990F80d598dE02d5143dC9A4422eC3a',
      entryPoint: '0x5FF137D4b0FDCD49DcA30c7CF57E578a026d2789',
      beaconAdminAddress: '0x99Ee7725D6a8f691d8B375e0aD33d1Aff2236618',
      beaconAdminCreationCode: '0x60a060405260405161059d...',
      signer: {
        clientId: process.env.MSA_CLIENT_ID!,
        versionId: process.env.MSA_VERSION_ID!
      }
    }
  });

  const userSalt = `user-${Date.now()}@example.com`;

  try {
    // 1. Predict wallet address
    console.log('🔮 Predicting wallet address...');
    const prediction = await client.predict({
      accounts: [{ walletCustody: CustodyType.ECDSA_VALIDATOR, salt: userSalt }]
    });
    const walletAddress = prediction.predictions[0].wallet;
    console.log(`✅ Predicted address: ${walletAddress}`);

    // 2. Check if wallet already exists
    console.log('🔍 Checking wallet existence...');
    const checkResult = await client.check({
      accounts: [{ walletCustody: CustodyType.ECDSA_VALIDATOR, salt: userSalt }]
    });
    
    if (checkResult.results[0].exists) {
      console.log('ℹ️ Wallet already exists, skipping creation');
    } else {
      // 3. Create wallet
      console.log('🏗️ Creating wallet...');
      const createResult = await client.create({
        accounts: [{ walletCustody: CustodyType.ECDSA_VALIDATOR, salt: userSalt }]
      });
      console.log(`✅ Wallet created! Tx: ${createResult.txHash}`);
    }

    // 4. Execute a transaction
    console.log('⚡ Executing transaction...');
    const executeResult = await client.execute({
      operations: [{
        walletCustody: CustodyType.ECDSA_VALIDATOR,
        salt: userSalt,
        to: '0x097d4Aed5924e2172451973153Fc0e03407eD1F9',
        funcSignature: 'approve(address,uint256)',
        funcParams: ['0xA65aae78EdEF916d4102BA7b5672068C0D35fbff', '1000000']
      }]
    });
    console.log(`✅ Transaction executed! Tx: ${executeResult.txHash}`);

    return {
      walletAddress,
      createTx: executeResult.txHash,
      executeTx: executeResult.txHash
    };

  } catch (error) {
    console.error('❌ Error:', error.message);
    throw error;
  }
}

// Run the workflow
walletWorkflow()
  .then(result => console.log('🎉 Workflow completed:', result))
  .catch(error => console.error('💥 Workflow failed:', error));
```

## Common Issues & Solutions

### 1. Insufficient Gas

**Error**: Transaction fails with "insufficient funds"

**Solution**: Ensure the predicted wallet address has enough native tokens:

```typescript
// Check balance before creating
const balance = await provider.getBalance(walletAddress);
console.log('Wallet balance:', ethers.utils.formatEther(balance));
```

### 2. Invalid Client ID

**Error**: "Invalid client ID" or authentication failure

**Solution**: Verify your Fireblocks credentials:

```bash
# Check environment variables
echo $MSA_CLIENT_ID
echo $MSA_VERSION_ID
```

### 3. Network Connection Issues

**Error**: "Network connection failed"

**Solution**: Verify RPC endpoint and network status:

```bash
# Test RPC endpoint
curl -X POST https://rpc-amoy.polygon.technology/ \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```
