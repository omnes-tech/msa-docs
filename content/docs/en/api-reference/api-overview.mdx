Flexible APIs for Account Abstraction wallet management, transaction execution, and blockchain interactions.

## Endpoint Reference

| API | Method | Description |
|-----|--------|-------------|
| [Predict Wallet](/docs/en/api-reference/predict-wallet) | POST | Predict wallet addresses before creation based on salt and custody type. |
| [Create Wallet](/docs/en/api-reference/create-wallet) | POST | Deploy new Account Abstraction wallets on the blockchain. |
| [Check Wallet](/docs/en/api-reference/check-wallet) | POST | Verify wallet existence and status on the blockchain. |
| [Execute Operation](/docs/en/api-reference/execute-operation) | POST | Execute operations with human-readable parameters. |
| [Execute Encoded](/docs/en/api-reference/execute-encoded) | POST | Execute pre-encoded UserOperations. |
| [Execute Passkey](/docs/en/api-reference/execute-passkey) | POST | Execute operations with passkey validation. |
| [Estimate Gas](/docs/en/api-reference/estimate-gas) | POST | Estimate gas costs for operations before execution. |
| [Read Contract](/docs/en/api-reference/read-contract) | POST | Read smart contract state from the blockchain. |
| [Get Receipt](/docs/en/api-reference/get-receipt) | POST | Get transaction receipts by transaction hash. |
| [Filter Events](/docs/en/api-reference/filter-events) | POST | Filter blockchain events based on specified criteria. |
| [Sign Message](/docs/en/api-reference/sign-message) | POST | Sign arbitrary messages with HSM/MPC keys. |
| [Passkey Hash](/docs/en/api-reference/passkey-hash) | POST | Generate passkey hashes for passkey-based operations. |
| [Transact Signer](/docs/en/api-reference/transact-signer) | POST | Execute direct HSM/MPC transactions. |
| [Unstuck Transaction](/docs/en/api-reference/unstuck-transaction) | POST | Resolve stuck transactions. |
| [Add Event ABI](/docs/en/api-reference/add-event-abi) | POST | Add custom event ABIs to the system. |
| [Add Error ABI](/docs/en/api-reference/add-error-abi) | POST | Add custom error ABIs to the system. |

## Authentication

All API endpoints require authentication using HSM/MPC credentials. Authentication is configured through the `signer` object in request settings.

### Signer Configuration

The `signer` object requires a `clientId` and either a `versionId` (for HSM) or `assetId` (for MPC):

**HSM Configuration:**
```json
{
  "signer": {
    "clientId": "your-fireblocks-client-id",
    "versionId": "1"
  }
}
```

**MPC Configuration:**
```json
{
  "signer": {
    "clientId": "your-fireblocks-client-id",
    "assetId": "ETH"
  }
}
```

Please contact the MSA team for HSM/MPC credentials and API access.

## Base URL

All API requests should be made to:

```
https://api.msa.omnes.tech
```

## Rate Limits

The MSA API implements rate limiting to ensure fair usage:

| Tier | Requests per Minute | Requests per Hour |
|------|---------------------|-------------------|
| Free | 60 | 1,000 |
| Pro | 300 | 10,000 |
| Enterprise | 1,000 | 50,000 |

## Error Codes

Common HTTP status codes and their meanings:

| Code | Status | Description |
|------|--------|-------------|
| 200 | OK | Request successful |
| 400 | Bad Request | Invalid request parameters |
| 401 | Unauthorized | Invalid authentication credentials |
| 422 | Unprocessable Entity | Request valid but execution failed |
| 429 | Too Many Requests | Rate limit exceeded |
| 500 | Internal Server Error | Server-side error |
