# TypeScript SDK

The MSA TypeScript SDK provides a type-safe, modern way to interact with the MSA API. Built with TypeScript-first approach, it offers excellent IntelliSense support, automatic error handling, and a clean, intuitive API.

## Installation

```bash
npm install @omnes/msa-sdk
# or
yarn add @omnes/msa-sdk
# or
pnpm add @omnes/msa-sdk
```

## Quick Start

```typescript
import { MSAClient, CustodyType } from '@omnes/msa-sdk';

// Initialize the client
const client = new MSAClient({
  baseURL: 'https://api.msa.omnes.tech',
  defaultSettings: {
    rpc: 'https://rpc-amoy.polygon.technology/',
    factory: '0xb09Fd1134553a43A3E02182a6B04F4dEBa7476F4',
    validator: '0x9bD18Da66990F80d598dE02d5143dC9A4422eC3a',
    entryPoint: '0x5FF137D4b0FDCD49DcA30c7CF57E578a026d2789',
    beaconAdminAddress: '0x99Ee7725D6a8f691d8B375e0aD33d1Aff2236618',
    signer: {
      clientId: process.env.MSA_CLIENT_ID!,
      versionId: process.env.MSA_VERSION_ID!
    }
  }
});

// Create a wallet
const result = await client.createWallet({
  walletCustody: CustodyType.ECDSA_VALIDATOR,
  salt: 'user@example.com'
});

console.log('Wallet created:', result.wallet);
```

## Error Handling

### Type-Safe Error Handling

```typescript
import { MSAError, MSAErrorCode } from '@omnes/msa-sdk';

try {
  const result = await client.createWallet({
    walletCustody: CustodyType.ECDSA_VALIDATOR,
    salt: 'user@example.com'
  });
} catch (error) {
  if (error instanceof MSAError) {
    switch (error.code) {
      case MSAErrorCode.INSUFFICIENT_FUNDS:
        console.error('Wallet needs more funds for gas');
        break;
      case MSAErrorCode.INVALID_CREDENTIALS:
        console.error('Check your Fireblocks credentials');
        break;
      case MSAErrorCode.WALLET_ALREADY_EXISTS:
        console.warn('Wallet already deployed');
        break;
      case MSAErrorCode.NETWORK_ERROR:
        console.error('Network connection failed');
        break;
      default:
        console.error('Unknown error:', error.message);
    }
  } else {
    console.error('Unexpected error:', error);
  }
}
```

## Advanced Usage

### Custom Network Configuration

```typescript
// Multi-network client
class MultiNetworkMSA {
  private clients: Map<number, MSAClient> = new Map();

  constructor(networks: NetworkConfig[]) {
    networks.forEach(network => {
      this.clients.set(network.chainId, new MSAClient({
        baseURL: 'https://api.msa.omnes.tech',
        defaultSettings: {
          rpc: network.rpc,
          factory: network.factory,
          validator: network.validator,
          entryPoint: network.entryPoint,
          beaconAdminAddress: network.beaconAdmin,
          signer: network.signer
        }
      }));
    });
  }

  getClient(chainId: number): MSAClient {
    const client = this.clients.get(chainId);
    if (!client) {
      throw new Error(`No client configured for chain ID ${chainId}`);
    }
    return client;
  }

  async createWalletOnNetwork(chainId: number, account: AccountInfo) {
    return this.getClient(chainId).createWallet(account);
  }
}
```

```typescript
export const useMSA = () => {

        versionId: process.env.NEXT_PUBLIC_MSA_VERSION_ID!
      }
    }
  }), []);

  const createWallet = useCallback(async (salt: string) => {
    return client.createWallet({
      walletCustody: CustodyType.ECDSA_VALIDATOR,
      salt
    });
  }, [client]);

  const executeTransaction = useCallback(async (
    salt: string,
    to: string,
    funcSignature: string,
    funcParams: any[]
  ) => {
    return client.execute({
      walletCustody: CustodyType.ECDSA_VALIDATOR,
      salt,
      to,
      funcSignature,
      funcParams
    });
  }, [client]);

  return {
    client,
    createWallet,
    executeTransaction
  };
};
```

```typescript
export const handleMSAError = (error: unknown) => {
  if (error instanceof MSAError) {
    // Log to monitoring service
    console.error('MSA API Error:', {
      code: error.code,
      message: error.message,
      details: error.details
    });
```

## SmartWallet SDK (Advanced)

For advanced use cases, MSA provides the **SmartWallet SDK** - a lower-level SDK that gives you complete control over UserOperation construction and signing.

### Installation

```bash
npm install @omnes/smartwallet-ts-sdk
```

### Key Features

- ✅ **Complete UserOp Control**: Build and sign UserOperations manually
- ✅ **Multiple Signers**: PKSigner, GCPSigner, MultisigSigner, PasskeySigner
- ✅ **Self & Remote Bundler**: Choose your bundler strategy
- ✅ **Custom Signatures**: Implement your own signing logic
- ✅ **Gas Optimization**: Fine-tune gas settings

### Quick Start with SmartWallet SDK

```typescript
import { SmartWallet, PKSigner, AccountOperations, Operation } from '@omnes/smartwallet-ts-sdk';

// Create signer
const signer = await PKSigner.create(privateKey as `0x${string}`);

// Create SmartWallet instance
const smartWallet = await SmartWallet.create(
  signer.signMessage,        // Messages sign method
  signer.signMessage,         // UserOp hash sign method
  signer.getEVMAddress(),    // Sender address
  rpcURL,                     // RPC endpoint
  apiKey                      // API key
);

// Build operations
const operations: Operation = {
  to: tokenAddress,
  value: BigInt(0),
  funcSignature: 'transfer(address,uint256)',
  params: [recipient, amount]
};

const accountOperations: AccountOperations[] = [{
  account: {
    walletCustody: 1, // ECDSA_VALIDATOR
    salt: 'user@example.com',
    publicKeys: []
  },
  operations: [operations],
  settings: {}
}];

// Build and send UserOperations
const result = await smartWallet.buildAndRequestSendUserOperations(
  accountOperations,
  [], // useABI
  []  // signers
);

console.log('Transaction hash:', result.response.txHash);
```

### Manual UserOp Construction

For complete control:

```typescript
// Build UserOperations (not signed)
const result = await smartWallet.buildUserOperations(
  accountOperations,
  [],
  []

// Sign manually
const signatures: `0x${string}`[] = [];
for (const userOp of result.userOps) {
  const signature = await signer.signMessage(toBytes(userOp.userOpHash));
  signatures.push(toHex(signature) as `0x${string}`);
}

// Execute with signatures
const response = await smartWallet.provideSignaturesAndRequestSendUserOperations(
  result.userOps,
  result.accessList,
  signatures,

);
```

### Complete Example

```typescript
import { SmartWallet, PKSigner, AccountOperations, Operation } from '@omnes/smartwallet-ts-sdk';

async function completeExample() {
  // 1. Create signer
  const signer = await PKSigner.create(privateKey as `0x${string}`);
  
  // 2. Create SmartWallet
  const smartWallet = await SmartWallet.create(
    signer.signMessage,
    signer.signMessage,
    signer.getEVMAddress(),
    rpcURL,
    apiKey
  );
  
  // 3. Build operations
  const operations: Operation = {
    to: tokenAddress,
    value: BigInt(0),
    funcSignature: 'transfer(address,uint256)',
    params: [recipient, amount]
  };
  
  const accountOperations: AccountOperations[] = [{
    account: {
      walletCustody: 1,
      salt: 'user@example.com',
      publicKeys: []
    },
    operations: [operations],
    settings: {}
  }];
  
  // 4. Execute
  const result = await smartWallet.buildAndRequestSendUserOperations(
    accountOperations,
    [],
    []
  );
  
  console.log('Transaction hash:', result.response.txHash);
  console.log('Status:', result.response.status);
  
  return result;
}
```
